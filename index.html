Casting sequence
  1. Print and finish the inner former; seal every layer line.
  2. Seat it in the bottom ring, then assemble the gasketed outer case.
  3. Apply release, pour pottery plaster, and let it set completely.
  4. Remove the printed tooling, flip the plaster block, dry it, then slip cast.

The printed case controls the plaster outside; the inner former creates the casting cavity and slip well. Uploaded STL files default to a split workflow because arbitrary parting surfaces and undercuts still require a mold-maker’s judgment.
